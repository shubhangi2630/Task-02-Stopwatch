# ⏱️ Task 2 – Stopwatch Web Application

## 📌 Overview

This project is a **Stopwatch Web Application** developed by me. The application provides a simple and interactive way to measure elapsed time using a clean and responsive user interface.

The stopwatch is built using **HTML, CSS, and JavaScript**, with JavaScript handling the timing functionality and user interactions.

## ✨ Features

* ▶️ **Start** the stopwatch
* ⏸️ **Pause** the stopwatch
* 🔄 **Reset** the stopwatch
* ⏱️ Displays elapsed time accurately
* 📱 Responsive design for different screen sizes
* 🎨 Simple and user-friendly interface
* ⚡ Interactive controls using JavaScript

## 🛠️ Technologies Used

* **HTML5** – Structure of the web page
* **CSS3** – Styling and responsive design
* **JavaScript** – Stopwatch functionality and user interactions

## 📂 Project Structure

Task-02-Stopwatch/
│
├── index.html

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Click **Start** to begin the stopwatch.
5. Use **Pause** to stop the timer temporarily.
6. Click **Reset** to start again from zero.

## 🎯 Objective

The objective of this task was to develop a functional stopwatch using JavaScript while practicing DOM manipulation, event handling, timing functions, and responsive web design.
